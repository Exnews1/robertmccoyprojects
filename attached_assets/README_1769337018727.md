## 🐛 Troubleshooting

### Issue: Images Not Showing
**Fix:** Check that PNG files are in `assets/images/` folder

### Issue: Styles Not Loading
**Fix:** Verify `style.css` is in the same folder as `index.html`

### Issue: JavaScript Not Working
**Fix:** Open browser console (F12) and check for errors

### Issue: Data Not Loading
**Fix:** Validate JSON files at jsonlint.com
