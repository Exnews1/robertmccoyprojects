🔧 Customization Guide
Change Chart Colors
Edit pages/charts.js lines 16-28:

const colors = {
    primary: '#YOUR_COLOR',
    secondary: '#YOUR_COLOR',
    // ... etc
};
Update Chart Data
Edit assets/data/adoption-data.json:

{
  "marketSize": {
    "2026": 11.5  // Update values here
  }
}
Charts update automatically!

Add New Chart
Add <canvas id="newChart"> to HTML
Create createNewChart() function in JS
Call in loadDataAndInitCharts()
