🛠 Technical Implementation (Simple)

Add query parameter:

/api/isr/demo?mode=sm
/api/isr/demo?mode=eso
/api/isr/demo?mode=combined

Backend logic:

if mode == "sm":
    return sm_insights

elif mode == "eso":
    return eso_insights

else:
    return combined_insights

No major refactor needed.
