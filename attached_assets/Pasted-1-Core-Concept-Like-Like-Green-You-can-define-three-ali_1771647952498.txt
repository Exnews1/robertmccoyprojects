5. Time Estimate Engine

You can compute rough ranges based on alignment + tier.

Example logic:

IF alignment == "green":
    time = 3–6 months

IF alignment == "yellow":
    time = 6–12 months

IF alignment == "red":
    time = 12–24 months

Then modify:

IF learner.has_degree:
    reduce time

IF learner.has_certifications:
    reduce time

IF career_tier == 2:
    add 3–6 months

This produces realistic estimates.
