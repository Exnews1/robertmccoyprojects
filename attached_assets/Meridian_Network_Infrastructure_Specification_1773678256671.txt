1. PURPOSE

This specification defines the technical requirements, standards,
and configurations for the Meridian Industrial Group corporate
network infrastructure across all facilities. All network equipment
procurement, installation, and configuration shall comply with
the requirements in this document.

2. NETWORK ARCHITECTURE

2.1 Core Network
The core network shall operate on a redundant spine-leaf
architecture with minimum 100 Gbps backbone links between spine
switches. All spine switches shall support Layer 3 routing with
BGP and OSPF protocols. Core network equipment shall provide
99.999 percent availability through redundant power supplies,
control planes, and fabric modules.

2.2 Access Layer
Access layer switches shall provide minimum 1 Gbps copper
connectivity to end-user devices and 10 Gbps uplinks to
distribution switches. Power over Ethernet (PoE+) support is
required on all access ports to support wireless access points,
IP phones, and security cameras.

2.3 Wireless Network
Wireless access points shall support Wi-Fi 6E (802.11ax) with
minimum 2x2 MIMO configuration. Wireless coverage shall provide
minimum -65 dBm signal strength in all occupied areas. Separate
SSIDs shall be maintained for corporate devices, guest access,
and IoT devices with network segmentation enforced at the
controller level.

3. SECURITY REQUIREMENTS

3.1 Network Segmentation
The network shall be segmented into the following zones:
  - Corporate zone: Employee workstations and applications
  - Production zone: Manufacturing execution systems and PLCs
  - DMZ: Public-facing services and vendor access
  - Management zone: Network infrastructure administration
  - IoT zone: Sensors, cameras, and building automation

Inter-zone traffic shall pass through next-generation firewall
inspection with application-layer filtering.

3.2 Access Control
All network access shall require 802.1X authentication. Devices
failing authentication shall be placed in a quarantine VLAN with
limited internet-only access. Network access control policies
shall enforce device compliance checks including operating system
patch level and antivirus status.

4. MONITORING AND MANAGEMENT

All network devices shall forward syslog data to the centralized
SIEM platform. SNMP v3 shall be configured on all managed devices.
Network performance monitoring shall track bandwidth utilization,
latency, packet loss, and device health metrics with 5-minute
polling intervals.
