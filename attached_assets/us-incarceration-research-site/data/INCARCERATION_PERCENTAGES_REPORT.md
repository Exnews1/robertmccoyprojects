## 📚 METHODOLOGY & SOURCES

### Data Sources (APA 7th Edition)

**Population Data:**
- U.S. Census Bureau. (2024). *State population totals: 2020-2024*. https://www.census.gov/data/tables/time-series/demo/popest/2020s-state-total.html

**Incarceration Data:**
- Prison Policy Initiative. (2024). *States of incarceration: The global context 2024*. https://www.prisonpolicy.org/

**Political Classification:**
- Ballotpedia. (2024). *State government trifectas*. Retrieved January 2026.

### Classification Methodology

**Political Party Classification:**
- **Red State (Republican):** Governor + State House + State Senate all controlled by Republicans
- **Blue State (Democratic):** Governor + State House + State Senate all controlled by Democrats  
- **Purple State (Split):** Mixed control (e.g., Republican governor with Democratic legislature, or vice versa)

**Percentage Calculation:**
```
Percentage Incarcerated = (Prison Population ÷ State Population) × 100
```

### Limitations

1. **Prison vs. Jail:** This analysis focuses on **prison** populations (state and federal facilities for sentenced individuals), not jail populations (local facilities for pre-trial detention and short sentences)

2. **Temporal Snapshot:** Data represents 2024 estimates and may not reflect recent policy changes

3. **Causation vs. Correlation:** Political party control is correlated with incarceration rates, but this does not prove causation. Many other factors influence incarceration rates including:
   - Historical sentencing policies
   - Crime rates
   - Socioeconomic factors
   - Judicial practices
   - Law enforcement practices
   - Drug policy approaches

4. **State vs. Federal:** Includes both state and federal prisoners attributed to each state
