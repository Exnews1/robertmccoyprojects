# ⚡ Quick Start Guide

## 🚀 Get Your Site Live in 5 Minutes!

### Option 1: Replit (Fastest - No Technical Skills Needed)

**Time: 2-3 minutes**

1. Go to [replit.com](https://replit.com) and sign up (free)
2. Click "+ Create Repl"
3. Choose "HTML, CSS, JS" template
4. Name it "us-incarceration-research"
5. Delete default files
6. Drag and drop this entire folder
7. Click "Run" button
8. **Done!** Your site is live at: `https://us-incarceration-research.[your-username].repl.co`

---

### Option 2: Local Testing (For Development)

**Time: 30 seconds**

```bash
# Navigate to folder
cd us-incarceration-research-site

# Start server (choose one):
python3 server.py          # Python
# OR
npx serve                  # Node.js
# OR
python3 -m http.server 8000  # Simple Python

# Open browser to:
http://localhost:8000
```

## 🔧 Troubleshooting

**Problem:** Charts not showing  
**Solution:** Check that CSV files are in `/data/` folder

**Problem:** CSS not loading  
**Solution:** Clear browser cache, check file paths

**Problem:** Mobile menu not working  
**Solution:** Make sure script.js is loaded
