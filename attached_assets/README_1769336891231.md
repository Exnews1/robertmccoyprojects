# AI Education Futures Hub - Replit Implementation Guide

## 📋 Overview

This directory contains **modular instructions** designed to be fed to Replit AI one module at a time. Each module is self-contained and builds upon the previous ones.

## 🎯 Purpose

These instructions allow you to build a comprehensive, interactive website about AI in education by:
1. Copying each module's content
2. Pasting it into Replit AI's chat
3. Letting Replit AI implement that specific module
4. Moving to the next module

## 📚 Module Structure

### Module 0: Project Overview
**File:** `00_PROJECT_OVERVIEW.md`  
**Purpose:** High-level project description, tech stack, structure, and design principles  
**When to use:** First - to give Replit AI context about the entire project

### Module 1: HTML Structure
**File:** `01_INDEX_HTML.md`  
**Purpose:** Complete landing page HTML with all sections  
**When to use:** After Module 0 - creates the foundation  
**Output:** `index.html` file

### Module 2: CSS Styling
**File:** `02_STYLE_CSS.md`  
**Purpose:** Complete design system with CSS variables and responsive layouts  
**When to use:** After Module 1 - adds all styling  
**Output:** `style.css` file

### Module 3: JavaScript Functionality
**File:** `03_SCRIPT_JS.md`  
**Purpose:** All interactive features, animations, and utilities  
**When to use:** After Module 2 - adds interactivity  
**Output:** `script.js` file

### Module 4: JSON Data Files
**File:** `04_DATA_FILES.md`  
**Purpose:** All research data, statistics, and content  
**When to use:** After Module 3 - populates the site with real data  
**Output:** Three JSON files in `assets/data/` directory

## 🚀 Implementation Workflow

### Step 1: Set Up Replit Project
1. Go to https://replit.com
2. Create new Repl → Select "HTML, CSS, JS" template
3. Name it: `AI-Education-Futures-Hub`

### Step 2: Feed Modules to Replit AI (In Order)

#### Module 0: Project Context
```
Prompt to Replit AI:
"I'm building an interactive educational website about AI in education. 
Here's the project overview and structure. Please read and confirm you 
understand the project scope."

[Paste content from 00_PROJECT_OVERVIEW.md]
```

#### Module 1: Create index.html
```

```

```
"Now create the main JavaScript file (script.js) with all interactive
```

#### Module 4: Create JSON Data Files
```
Prompt to Replit AI:
```

## 🔧 Troubleshooting

### Issue: Images Not Showing
**Solution:** Verify image paths are correct and files are uploaded to `assets/images/`

### Issue: Styles Not Applied
**Solution:** Check that `<link rel="stylesheet" href="style.css">` is in `<head>`

### Issue: JavaScript Not Working
**Solution:** Check browser console (F12) for errors, verify `<script src="script.js">` is before `</body>`

### Issue: Data Not Loading
**Solution:** Check that JSON files are valid (use JSONLint.com) and paths are correct

## 💡 Tips for Working with Replit AI

### 1. Be Specific
Instead of: "Add a navigation bar"
Use: "Add a sticky navigation bar with mobile hamburger menu that includes links to Pathways, Sectors, Tools, Resources, About, and Get Started"

### 2. One Module at a Time
Don't paste all modules at once. Feed them sequentially so Replit AI can focus on one task.

### 3. Test Incrementally
Test after each module to catch issues early.

### 4. Use Follow-Up Prompts
If something doesn't work:
- "The mobile menu isn't opening. Can you debug the JavaScript?"
- "The colors look off. Can you adjust the CSS variables?"
- "The JSON file has a syntax error. Can you fix it?"

### 5. Ask for Explanations
If you want to understand:
- "Can you explain how the statistics counter animation works?"
- "What does the Intersection Observer do in the scroll animations?"
