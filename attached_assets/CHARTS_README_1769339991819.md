# Interactive Chart.js Visualizations

## Overview

This folder contains a complete data visualization page with 8 interactive Chart.js charts displaying AI adoption trends in education.

## Files Created

### 1. data-visualizations.html (Main Page)
- **Location:** `/pages/data-visualizations.html`
- **Size:** ~15KB
- **Purpose:** Complete visualization dashboard page

**Features:**
- 8 interactive Chart.js visualizations
- Responsive design (mobile, tablet, desktop)
- Insights section for each chart
- Professional styling matching site theme
- Navigation and footer integration

### 2. charts.js (Chart Logic)
- **Location:** `/pages/charts.js`
- **Size:** ~12KB
- **Purpose:** All Chart.js initialization and configuration

**Features:**
- Loads data from `adoption-data.json`
- Creates 8 different chart types
- Custom colors matching brand
- Interactive tooltips
- Responsive configurations

## How to Use

### Viewing the Page

1. **Local Testing:**
   ```bash
   # Open in browser
   open pages/data-visualizations.html
   
   # Or run local server
   python3 -m http.server 8000
   # Then visit: http://localhost:8000/pages/data-visualizations.html
   ```

2. **After Deployment:**
   - URL: `https://your-site.com/pages/data-visualizations.html`
   - Or click "View Interactive Charts" button on homepage

### Customizing Charts

**Change Colors:**
Edit `charts.js` lines 16-28:
```javascript
const colors = {
    primary: '#2E86AB',    // Change this
    secondary: '#06A77D',  // Change this
    // ... etc
};
```

**Update Data:**
Charts automatically load from `../assets/data/adoption-data.json`
- Edit JSON file to update all charts
- No code changes needed

**Add New Charts:**
1. Add new `<canvas>` in HTML
2. Create new function in `charts.js`
3. Call function in `loadDataAndInitCharts()`

## Troubleshooting

### Issue: Charts Not Rendering
**Solution:**
- Check browser console for errors
- Verify Chart.js CDN is loading
- Ensure JSON data file exists
- Check file paths are correct

### Issue: Data Not Loading
**Solution:**
- Verify `adoption-data.json` path
- Check JSON syntax (use jsonlint.com)
- Ensure fetch API is supported
- Check CORS if using file://

### Issue: Responsive Issues
**Solution:**
- Check viewport meta tag
- Verify CSS media queries
- Test on real devices
- Use browser DevTools

### Issue: Performance Slow
**Solution:**
- Reduce chart animations
- Optimize data points
- Lazy load charts
- Use requestAnimationFrame
