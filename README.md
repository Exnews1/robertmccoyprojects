# Editorial Workflow Studio transfer

This branch carries a complete Git bundle exported from the education Replit workspace. The bundle includes every tracked file and the complete local commit history through commit cfaad7d.

## Restore in the other Replit account

1. Clone this transfer branch:

   git clone --branch education-workspace https://github.com/Exnews1/robertmccoyprojects.git editorial-workflow-transfer

2. Create a normal working repository from the bundle:

   git clone editorial-workflow-transfer/Editorial-Workflow-Studio.bundle Editorial-Workflow-Studio

3. Import the new Editorial-Workflow-Studio directory in Replit.

The existing main branch of Exnews1/robertmccoyprojects was not modified.
